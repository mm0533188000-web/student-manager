# student-manager
#Project for managing students data using Python and CSV

## Overview
This project allows loading, saving, and managing student data efficiently through structured Python functions and standard CSV libraries.

## Features
* **Load Students (`load_students`)**: Reads student records from a CSV file into a list of dictionaries, returning an empty list if the file doesn't exist.
* **Save Students (`save_students`)**: Writes student lists back to a CSV file.
